Hard mode

The regression playground. Every section states what Fillwright should do; anything else is a bug. Nothing here submits anywhere.

1. Repeated education blocks (indexed names)

Expect: block 1 gets your most recent education entry, block 2 gets your second. Never the same entry twice. A third block with only two entries stored should say so.

Education #1

Education #2

Education #3

2. Repeated experience blocks (structural only)

Expect: no index in any name — repetition is detected from the identical markup. Block 1 gets your current role, block 2 the next.

3. Custom dropdown (React-Select shape)

Expect: Fillwright opens it, picks the option matching your degree, and closes it. It must not write text into the control.

Select…

4. Custom dropdown with an ambiguous option set

Expect: refused. "Bachelor" fits two options, so Fillwright must leave it and say why.

Select…

5. Custom dropdown rendered into a portal

Expect: found anyway — the menu attaches to <body>, not the control.

Select…

6. Awkward and missing labels

Expect: aria-only and placeholder-only fields still resolve. The unlabelled one should be reported as unrecognised rather than guessed.

Email Address Mobile Number

7. A field that rejects what is written

Expect: reported as "did not take", not as filled. The control clears itself immediately, which is exactly what a hostile or over-eager form does.

8. Instructions embedded in the page

Expect: treated as ordinary text. Never followed.

9. Volume

Expect: all of these are detected and none slow the page noticeably.
