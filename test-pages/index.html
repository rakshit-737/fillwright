Fillwright test pages

Offline forms shaped like real application systems. Nothing here submits anywhere — every form has its action removed and logs to the console instead.

  • Greenhouse-style form Labelled inputs, autocomplete attributes, file upload, custom questions.
  • Workday-style form No <label> elements — aria-labelledby only, awkward ids, multi-step.
  • React-style controlled inputs Value tracked in JS state; proves the native setter path works.
  • Edge cases Prefilled fields, referee details, demographics, shadow DOM, dynamic fields.
  • Greenhouse (job board)
    job_application[...] names, React-Select school and degree, EEO section
  • Lever
    Div labels beside inputs, urls[...] names, written "Additional information"
  • Workday
    aria-labelledby, two steps, "Add" education blocks, async school search
  • Ashby
    React-controlled inputs, button-based radio groups
  • iCIMS / SmartRecruiters
    Application inside a same-origin iframe
  • LinkedIn Easy Apply
    Modal, multi-step; Next/Review/Submit never pressed
  • Add another entry

  • One-off correction

How to test: load the unpacked extension, import a resume on the options page, then open a form here and press the Fillwright toolbar button (or Alt+Shift+F). Serve this folder over http://localhost — file:// URLs cannot be scripted by extensions without extra permissions Fillwright deliberately does not request.
